## 1. 五条原则

1. **白纸 + 墨字 + 一处荧光**。默认白底黑字；荧光绿（lime）只出现在「当前可操作」的位置，一屏最多一处。
2. **物体感优先于装饰**。玻璃、层叠、实体文件夹都要有结构理由；纯发光/纯渐变/纯阴影堆叠不做。
3. **只用桌面端**。不写移动断点，不写触屏交互分支。
4. **文案全英文**，界面里不出现中文（含标点）。
5. **符号不当图标**。箭头、✦、▷、⌘ 这类字符一律不进 UI；要么是 SVG 线性图标，要么是文字。

### 3.2 提案字号 scale

```
--text-micro:10px   /* meta、角标、表格辅助 */
--text-small:12px   /* 说明、次级信息 */
--text-body:14px    /* 正文基线 */
--text-lead:17px    /* 卡片标题、导语 */
--text-h3:22px      /* 小节标题 */
--text-h2:30px      /* 段落标题 */
--text-h1:36px      /* 页面标题 */
--text-display:48px /* 首屏/海报 */
--text-eyebrow:10px + letter-spacing:.18em + uppercase
```
行高：`micro/small 1.4` · `body 1.6` · `lead 1.4` · `h*  1.2` · `display 1.0`

**取舍说明**：现在 65 种字号会归一成 8 级。被合并掉的 9/11/13/15/16 会让部分密集界面（工作室表格、侧栏）显得略松。若你希望保留密度，见 D4 的 B 案。
