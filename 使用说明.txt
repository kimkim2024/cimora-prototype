本包来自当前旧版 prototype 源码，包含截至打包时已完成的修改。
新版 Cimora-Demo-20261116-Win-Mac 不在本包中。

一、推荐启动方式（Windows / Mac）
1. 完整解压 ZIP，保留全部文件和子文件夹，不要在压缩软件内直接运行。
2. 安装 Node.js 18 或更新版本：https://nodejs.org/ 。不需要 npm install。
3. Windows：双击 start-windows.cmd。
   Mac：在终端输入 bash 和一个空格，将 start-macos.command 拖进终端，然后按回车。
4. 启动后自动打开浏览器。建议使用 Chrome 或 Edge。
   可手动打开：http://127.0.0.1:4186/index.html#/app
5. 演示期间保持终端窗口打开；Ctrl+C 可停止服务。服务仅监听本机。
6. 如果 4186 端口被占用，在本文件夹终端执行：
   node local-server.cjs 4187 --open
   使用新端口可能会显示独立的浏览器本地数据。

二、快速浏览（无需安装）
用 Chrome 或 Edge 打开“开始体验.html”。
文件方式可以浏览原型，但部分资源、画布导出及跨页面操作受浏览器限制。
需要完整交互时，请使用上面的本地服务方式。

三、版本与示例
包含旧版创作空间、我的项目、任务中心、导出中心、回收站和个人中心等界面。
个人中心已包含积分概览、时间筛选、跨日期明细示例，以及最高 480px 的内部滚动列表与固定表头。
积分使用明细默认展示样例，可切换“查看我的用量”；示例不修改钱包余额。
包内预置故事、漫画和视频交互案例，入口位于开始页及创作工作台。
个人中心统一容器对齐的方案尚未实施，本包保留打包时已完成的样式。

四、数据说明
本包包含代码、素材与预置案例，不包含发送者浏览器里自行创建或修改的项目、上传文件和登录信息。
接收者的操作保存在其浏览器本机，不会自动同步给发送者。
如需另行携带自建项目，请在个人中心“资料与设置”中下载完整备份，再通过“从备份恢复”导入。
当前为交互原型，模型生成、积分与支付均为演示；不发生真实模型扣费或支付。
视频示例以静态镜头交互为主，并非完整生成的视频。系统语音试听取决于设备音色。
