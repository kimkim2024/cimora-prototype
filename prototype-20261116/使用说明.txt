Cimora 最新产品本地演示版（打包日期见版本信息.json）

一、直接打开（Mac / Windows）
1. 先完整解压 ZIP，保留所有文件和子文件夹。
2. 用 Chrome 或 Edge 打开“开始体验.html”。无需安装依赖、无需联网启动服务。
3. 首次体验建议点击“全流程故事示例”“两集漫画示例”或“两集视频交互示例”，直接打开已填好的完整案例。
4. 工作台顶部也有“打开完整演示案例”入口；进入案例后，可点击四步体验说明逐步查看内容与操作。

二、包含内容
完整产品当前运行界面；最新导航顺序；故事、漫画、视频、资产库、创作工具等入口。
包含新版官网、独立功能与工具介绍、创作指南、公开案例阅读，以及个人中心、创作者中心、作品广场和创作市场的演示交互。
故事：全流程创作体验示例《离城之前》，10 集正文及上游设定。
漫画：同故事前两集，12 页成品及视觉资产、分页，可在最新工作台查看。
视频：同故事前两集的镜头静态示例，支持流程 / 画布切换和整集制作三轨交互。
创作工具：最新角色、绘图、动态、配音、音乐与音效工具；包含新改版的图片高清与压缩，已合并声音入口并移除三项质检工具。
工具示例图片、音频和短片随包保留；可使用预置示例或上传本机文件体验。图片压缩真实执行，高清仅为 2 / 4 倍插值放大预览，未接 AI 修复。
不会附带开发测试日志、验收截图或个人浏览器缓存。

三、本地服务方式（推荐用于正式演示和完整的同源体验）
需要已安装 Node.js 18 或更新版本，无需 npm install。
Windows：双击 start-windows.cmd，保持终端打开。
Mac：用终端进入本文件夹，执行 bash start-macos.command。
也可在两种系统终端中执行 node local-server.cjs。
浏览器打开 http://127.0.0.1:4186/开始体验.html
如端口被占用：node local-server.cjs 4187，并打开对应端口。
关闭终端或按 Ctrl+C 停止服务。服务只监听本机地址。

四、数据和边界
打开时自动补齐缺失的公开演示工程；已有空白或自建项目也可进入完整案例，保留原有工程和编辑内容。
编辑保存在浏览器本地；不同浏览器、不同解压路径，以及文件方式 / 服务方式的存储可能独立。
更换设备不会自动带走你后续编辑的数据；包内预置示例始终随文件保留。
付费模型未接入，生成按钮展示本地交互 / 候选请求，不会真实生成视频或扣费。
漫画图为已完成真实图片。视频示例是静态镜头，不是完整 MP4。
配音工具含预置试听，也会使用浏览器系统语音；系统语音的中文效果取决于本机音色。音乐与音效为本地合成演示。
工具内常用示例已适配离线读取和图片处理。直接打开文件时，部分浏览器仍会限制项目外部参考图的画布导出、麦克风或跨页面存储；如遇限制，请使用本地服务脚本。页面提示的示例、预览和待接模型边界仍然有效。
主站入口 index.html 是新版官网，点击开始创作进入工作台；开始体验.html 提供三个完整案例直达入口。历史演示页面仅用于保留作品阅读。
